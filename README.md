# Penalty League

L’obiettivo di questo lavoro è stato lo sviluppo di un’applicazione desktop, denominata Penalty League, che realizza una simulazione di calci di rigore.
L’applicazione è stata implementata utilizzando la tecnologia JFC/Swing in modo da favorire un’ampia portabilità su diversi sistemi operativi (piattaforme), riducendo al minimo eventuali modifiche al codice sorgente. Tuttavia, il codice prodotto è stato testato e ottimizzato per il sistema operativo Windows 11.

[Tesina completa](./tesina/PenaltyLeague_Tesina.pdf)

Per avviare l'applicazione è sufficiente eseguire il file .jar presente in dist\artifacts\PenaltyLeague_jar
